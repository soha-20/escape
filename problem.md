# Escape Game

## Problem
Nowadays escape games are not prevailing so much and most of the users do not have any new game that is actually thrilling or gives them joy in their free time. This game should not be like normal mobile phones game that distracts them. There is not fun  escape game they can start right away from the terminal they have already open in their laptops, which opens in a game window with real figures and graphics, with fun and feeling rushed. 

## Initial Requirements
- R1: The game starts and the user (player) has to escape from the grim reaper who is the villian.
- R2: The game will have hurdles like maze, the player has to follow the hints or signs telling which way to follow. For example: One red text on wall saying,"Wanna get stuck?".
- R3: The users loses the game, once the grim reaper catches him.
